We work across software, websites, applications, and networks. The part we go deepest on is
stopping finished software from being cracked, copied, or picked apart.

Everything we ship, we built ourselves. No off-the-shelf packer, no licensed third-party
engine, nothing rebadged.

## What we build

### Cryarmor

Code virtualization and anti-tamper. Your code gets turned into something nobody can read,
every build looks different so one crack never works twice, and tampering gets caught while
your program runs instead of ignored.

### CryKey

License and activation management. Issue, verify, and revoke licenses from one place, gating
by seat, subscription, or hardware fingerprint, without ever shipping your license logic in
the clear.

Each product is complete on its own. Use whichever solves your problem, or run both and they
fit together.

## This organization

Open source tooling, SDK clients, and examples. Our Python packages are published under
[pypi.org/org/cryav](https://pypi.org/org/cryav/).
